开发本地服务签名密钥轮换验证器，全部密钥为自行生成的测试字节，标准库 HMAC-SHA256 仅为合成运维事件签名。一个设备组任一时刻有唯一活动代，另可有预发布代及有限期验签旧代。活动代由 SQLite 决定，密钥材料写入本题专用的两个独立本地不可变文件，数据库保存确切代数和两个副本的期望摘要。文件先安全落盘并校验后才允许提交活动指针。新旧代内容相同也不得复用代数，旧代一旦吊销不得重新发行。

至少两个独立工作进程可以并发准备和发布。持久签名操作要在同一事务内重读活动代并原子登记结果与请求回执；提交前发现材料不可用要失败关闭。读者可使用通过摘要检查的同代冗余副本，两个副本都缺失或损坏时不得静默回到旧代。恢复区分已提交代、与当前回执绑定的阶段和未确认的孤立准备物，清理只动本题创建且可证明未被授权引用的文件。

用 Windows 进程同步点测试写一半文件、两副本落盘但指针未提交、指针已提交未响应的真实终止。同一代两写者竞争、预发布完成后基准被另一进程替换、单副本损坏及恰到旧代截止均要给可重放场景，证明不会签出未授权代次、不会返回混合材料，也不会在日志或回执泄漏任何密钥。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
